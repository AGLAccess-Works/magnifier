# Contributing and review feedback

Magnifier is maintained by Alex Liddell / AGL Access Works. Please open an issue before proposing a substantial change.

For a bug report, include your Windows version, source commit, build configuration, reproduction steps, expected behaviour and actual behaviour. For accessibility feedback, describe the task and access tools involved; no diagnosis or medical information is needed. Remove personal information from screenshots, logs and settings.

For a pull request, explain the user-visible result, reference the issue, and record the checks you ran. Follow the existing code style and keep changes focused. Windows integration and accessibility changes need appropriate hands-on verification as well as automated checks. See [the review guide](REVIEW.md).

Review feedback is welcome; any reuse or contribution permissions should be agreed with the maintainer because no software licence has yet been selected. Report security concerns through [GitHub private vulnerability reporting](https://github.com/AGLAccess-Works/magnifier/security/advisories/new).
